Polyphase provides two animation asset types. `SkeletalAnimationAsset` stores a standalone bone-animation clip decoupled from any specific mesh, enabling retargeting and cross-rig sharing. `SpriteAnimation` stores a sequence of texture frames (or an atlas-grid slice) for 2D sprite animation. Both inherit from [`Asset`](/lua/assets/asset).

---

## SkeletalAnimationAsset

A reusable skeletal animation clip. Channels are keyed by bone **name**, so the same asset can drive multiple compatible rigs. Clips are created by:
- Extracting from a `SkeletalMesh` (right-click → Extract Animations…)
- Importing animation-only files
- Baking a retarget

Inherits: `Asset`

### `SkeletalAnimationAsset:GetClipName()`

Get the clip name used by `SkeletalMesh3D:PlayAnimation()`. Defaults to the source clip name and is preserved across retarget bakes.

**Returns:** `string` — clip name.

---

### `SkeletalAnimationAsset:GetDuration()`

Get the clip duration in raw timeline ticks. Divide by `GetTicksPerSecond()` to get seconds.

**Returns:** `number` — duration in ticks.

---

### `SkeletalAnimationAsset:GetDurationSeconds()`

Get the clip duration in seconds.

**Returns:** `number` — duration in seconds.

---

### `SkeletalAnimationAsset:GetTicksPerSecond()`

Get the tick rate. GLB exports from Blender use 1000 to work around Assimp handling.

**Returns:** `number` — ticks per second.

---

### `SkeletalAnimationAsset:GetSourceRigName()`

Get the name of the rig this clip was authored against. Used for tooling diagnostics; not read at runtime.

**Returns:** `string` — source rig name.

---

### `SkeletalAnimationAsset:GetNumChannels()`

Get the number of bone channels in this clip. Bones not in this list keep their bind-pose transform at runtime.

**Returns:** `integer` — channel count.

---

### `SkeletalAnimationAsset:GetChannelBoneName(index)`

Get the bone name a channel is keyed on.

| Parameter | Type | Description |
|-----------|------|-------------|
| `index` | `integer` | 1-based channel index. |

**Returns:** `string` — bone name, or `nil` if out of range.

```lua
local clip = LoadAsset("Animations/Anim_Walk")
Log.Debug("Clip: "     .. clip:GetClipName())
Log.Debug("Duration: " .. clip:GetDurationSeconds() .. "s")
Log.Debug("Channels: " .. clip:GetNumChannels())

-- Print all animated bone names
for i = 1, clip:GetNumChannels() do
    Log.Debug("  " .. clip:GetChannelBoneName(i))
end
```

---

### Adding clips to a SkeletalMesh3D node

Once loaded, a `SkeletalAnimationAsset` must be registered on the node before `PlayAnimation` can resolve its name:

```lua
function Character:Start()
    local walkClip = LoadAsset("Animations/Anim_Walk")
    self.mesh:AddAnimationAsset(walkClip)
    self.mesh:PlayAnimation("Walk", 0, true)
end
```

See [`SkeletalMesh3D:AddAnimationAsset`](/lua/nodes/mesh-nodes#skeletalmesh3daddanimationassetasset) for the full API.

## SpriteAnimation

A `SpriteAnimation` asset defines a named animation clip as either a sequence of individual textures (**Discrete** mode) or cells sliced from a packed sprite sheet (**AtlasGrid** mode).

Inherits: `Asset`

### Clip Identity

#### `SpriteAnimation:GetAnimationName()` / `SpriteAnimation:SetAnimationName(name)`

The name used by `PlayAnimation(name)` on sprite animator nodes. If empty, the asset filename is used.

---

### Playback Settings

#### `SpriteAnimation:GetFps()` / `SpriteAnimation:SetFps(fps)`

Playback frame rate.

| Parameter | Type | Description |
|-----------|------|-------------|
| `fps` | `number` | Frames per second. |

---

#### `SpriteAnimation:GetLoop()` / `SpriteAnimation:SetLoop(loop)`

Whether the animation loops by default.

---

#### `SpriteAnimation:GetFrameCount()`

Total number of frames. In Discrete mode this is the `Frames` array size; in AtlasGrid mode it is the frame-indices list size.

**Returns:** `integer` — frame count.

---

### Mode

#### `SpriteAnimation:GetMode()` / `SpriteAnimation:SetMode(mode)`

Frame source mode.

| Value | Mode |
|-------|------|
| `0` | Discrete — one `Texture` asset per frame |
| `1` | AtlasGrid — cells from a single atlas texture |

---

### Discrete Mode

#### `SpriteAnimation:AddFrame(texture)`

Append a `Texture` to the frame list.

| Parameter | Type | Description |
|-----------|------|-------------|
| `texture` | `Texture` | Texture for this frame. |

---

#### `SpriteAnimation:ClearFrames()`

Remove all frames from the list.

---

### AtlasGrid Mode

#### `SpriteAnimation:GetAtlasTexture()` / `SpriteAnimation:SetAtlasTexture(texture)`

The packed sprite-sheet texture.

---

#### `SpriteAnimation:SetAtlasGrid(cols, rows)`

Set the grid dimensions (number of columns and rows in the atlas).

| Parameter | Type | Description |
|-----------|------|-------------|
| `cols` | `integer` | Number of columns. |
| `rows` | `integer` | Number of rows. |

---

#### `SpriteAnimation:SetAtlasMargin(x, y)`

Pixel margin around the outer edge of the grid.

| Parameter | Type | Description |
|-----------|------|-------------|
| `x` | `integer` | Horizontal margin in pixels. |
| `y` | `integer` | Vertical margin in pixels. |

---

#### `SpriteAnimation:SetAtlasSpacing(x, y)`

Pixel spacing between adjacent cells.

| Parameter | Type | Description |
|-----------|------|-------------|
| `x` | `integer` | Horizontal spacing in pixels. |
| `y` | `integer` | Vertical spacing in pixels. |

---

## Examples

### Inspecting a loaded SpriteAnimation

```lua
local anim = LoadAsset("Animations/Anim_Walk")
Log.Debug("Clip: "   .. anim:GetAnimationName())
Log.Debug("FPS: "    .. anim:GetFps())
Log.Debug("Frames: " .. anim:GetFrameCount())
Log.Debug("Loops: "  .. tostring(anim:GetLoop()))
Log.Debug("Mode: "   .. anim:GetMode())  -- 0 = Discrete, 1 = AtlasGrid
```

### Building a Discrete animation from individual textures

```lua
function ItemPickup:Start()
    local anim = LoadAsset("Animations/Anim_Pickup")
    anim:SetMode(0)
    anim:ClearFrames()
    anim:AddFrame(LoadAsset("Textures/T_Pickup_01"))
    anim:AddFrame(LoadAsset("Textures/T_Pickup_02"))
    anim:AddFrame(LoadAsset("Textures/T_Pickup_03"))
    anim:SetFps(8.0)
    anim:SetLoop(false)
end
```

### Configuring an AtlasGrid animation from script

```lua
function SetupWalkSheet:Start()
    local anim = LoadAsset("Animations/Anim_AtlasWalk")
    anim:SetMode(1)  -- AtlasGrid
    anim:SetAtlasTexture(LoadAsset("Textures/T_CharacterSheet"))
    anim:SetAtlasGrid(8, 4)      -- 8 columns × 4 rows
    anim:SetAtlasMargin(0, 0)
    anim:SetAtlasSpacing(2, 2)   -- 2px between cells
    anim:SetFps(12.0)
    anim:SetLoop(true)
end
```

<Tip>The **Edit Atlas Frames…** button in the asset inspector lets you visually click cells in the atlas to build the playback order. This is usually easier than constructing it programmatically.</Tip>
