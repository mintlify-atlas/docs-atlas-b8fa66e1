Polyphase supports two material pipelines. **MaterialBase / MaterialInstance** use custom GLSL shaders and are only available on Vulkan platforms. **MaterialLite** is a simpler, cross-platform material that supports textures, colors, blend modes, fresnel, UV animation, and TEV modes.

All material types inherit from `Material` which itself inherits from [`Asset`](/lua/assets/asset).

---

## Material (base class)

`Material` provides shared queries and the parameter API used by MaterialBase and MaterialInstance.

### Type Checks

#### `Material:IsBase()`

**Returns:** `boolean` — `true` if this is a `MaterialBase`.

---

#### `Material:IsInstance()`

**Returns:** `boolean` — `true` if this is a `MaterialInstance`.

---

#### `Material:IsLite()`

**Returns:** `boolean` — `true` if this is a `MaterialLite`.

---

### Shader Parameters (MaterialBase / MaterialInstance only)

#### `Material:SetScalarParameter(name, value)`

Set a named scalar parameter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Parameter name. |
| `value` | `number` | Scalar value. |

---

#### `Material:GetScalarParameter(name)`

Get a named scalar parameter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Parameter name. |

**Returns:** `number` — current value.

---

#### `Material:SetVectorParameter(name, value)`

Set a named vector parameter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Parameter name. |
| `value` | `Vector` | Vector value. |

---

#### `Material:GetVectorParameter(name)`

**Returns:** `Vector` — current value.

---

#### `Material:SetTextureParameter(name, value)`

Set a named texture parameter.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Parameter name. |
| `value` | `Texture` | Texture asset. |

---

#### `Material:GetTextureParameter(name)`

**Returns:** `Texture` — current texture.

---

### Rendering Properties (read-only on MaterialBase/Instance)

#### `Material:GetBlendMode()`

Get the blend mode. See `BlendMode` enum: `Opaque`, `Masked`, `Translucent`, `Additive`.

**Returns:** `integer` — `BlendMode` value.

---

#### `Material:GetMaskCutoff()`

Get the alpha mask discard threshold (0–1). Fragments below this alpha are discarded in `Masked` mode.

**Returns:** `number` — cutoff value.

---

#### `Material:GetSortPriority()`

Translucent sort priority. Same-priority objects are sorted by depth.

**Returns:** `integer` — sort priority.

---

#### `Material:IsDepthTestDisabled()`

**Returns:** `boolean` — `true` if depth testing is disabled.

---

#### `Material:ShouldApplyFog()`

**Returns:** `boolean` — `true` if fog is applied to fragments.

---

#### `Material:GetCullMode()`

Get the triangle cull mode. See `CullMode` enum: `None`, `Back`, `Front`.

**Returns:** `integer` — `CullMode` value.

---

## MaterialBase

`MaterialBase` compiles from a custom GLSL vertex and fragment shader file. It is Vulkan-only.

Inherits: `Material` → `Asset`

`MaterialBase` has no additional Lua methods beyond `Material`. Parameters are set in the shader file; use `SetScalarParameter`, `SetVectorParameter`, and `SetTextureParameter` to drive them from Lua.

---

## MaterialInstance

`MaterialInstance` references a `MaterialBase` and overrides its default parameter values. The shader is not recompiled — only the uniform data changes.

Inherits: `Material` → `Asset`

### `MaterialInstance.Create(srcMat)`

Create a new `MaterialInstance` from a source `MaterialBase` or another `MaterialInstance`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `srcMat` | `Material` | Source material to inherit from. |

**Returns:** `MaterialInstance` — newly created instance.

```lua
local base  = LoadAsset("Materials/M_PBR_Base")
local inst  = MaterialInstance.Create(base)
inst:SetVectorParameter("AlbedoColor", Vec(1, 0, 0, 1))
self.mesh:SetMaterialOverride(inst)
```

---

### `MaterialInstance:GetBaseMaterial()`

Get the `MaterialBase` this instance references.

**Returns:** `MaterialBase` — base material.

---

### `MaterialInstance:SetBaseMaterial(base)`

Change the base material this instance references.

| Parameter | Type | Description |
|-----------|------|-------------|
| `base` | `MaterialBase` | New base material. |

---

## MaterialLite

`MaterialLite` is a cross-platform material that works on all Polyphase target platforms. It supports up to four texture slots, a color tint, blend mode, UV animation, fresnel, specular, opacity, and the TEV compositing system for older hardware.

Inherits: `Material` → `Asset`

### `MaterialLite.Create(srcMat)`

Create a new `MaterialLite`, optionally copying properties from an existing one.

| Parameter | Type | Description |
|-----------|------|-------------|
| `srcMat` | `MaterialLite` | Optional source to copy from. |

**Returns:** `MaterialLite` — newly created material.

```lua
local mat = MaterialLite.Create()
mat:SetColor(Vec(0.8, 0.2, 0.2, 1.0))
mat:SetBlendMode(BlendMode.Opaque)
```

### UV Mapping

#### `MaterialLite:GetUvMap(slot)` / `MaterialLite:SetUvMap(slot, uvMap)`

Get or set which UV channel (1 or 2) is used for a given texture slot.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slot` | `integer` | Texture slot (1–4). |
| `uvMap` | `integer` | UV channel (1 or 2). |

---

### TEV Modes

TEV (Texture Environment) modes control how multiple textures are combined. See `TevMode` enum: `Replace`, `Modulate`, `Decal`, `Add`, `SignedAdd`, `Subtract`, `Interpolate`.

#### `MaterialLite:GetTevMode(slot)` / `MaterialLite:SetTevMode(slot, tevMode)`

Get or set the TEV compositing mode for a texture slot.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slot` | `integer` | Texture slot. |
| `tevMode` | `integer` | `TevMode` enum value. |

## Usage Example

```lua
-- Create a MaterialLite for a lava effect with UV scroll
function LavaPlane:Start()
    local mat = MaterialLite.Create()
    mat:SetTexture(1, LoadAsset("Textures/T_Lava"))
    mat:SetColor(Vec(1, 0.4, 0, 1))
    mat:SetShadingModel(ShadingModel.Unlit)
    mat:SetBlendMode(BlendMode.Opaque)
    self.material = mat
    self:SetMaterialOverride(mat)
end

function LavaPlane:Tick(dt)
    local offset = self.material:GetUvOffset()
    self.material:SetUvOffset(Vec(offset.x + dt * 0.05, offset.y + dt * 0.02))
end
```
