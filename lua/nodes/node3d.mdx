sidebarTitle: "Node3D"
description: "Node3D adds a full 3D transform to any node: position, rotation (Euler & quaternion), scale, world-space queries, LookAt, and bone/socket attachment."
---

`Node3D` extends `Node` with a complete 3D transform. Every 3D scene object — meshes, lights, cameras, particles — inherits from `Node3D`. A node's final world-space transform is the product of its own relative transform and all ancestor transforms up the hierarchy.

All methods on the [Node base class](/lua/nodes/node) are also available on `Node3D`.

---

## Relative Position

### `Node3D:GetPosition()`

Get this node's position relative to its parent.

**Returns:** `Vector` — relative position.

---

### `Node3D:SetPosition(position)`

Set this node's relative position.

| Parameter | Type | Description |
|-----------|------|-------------|
| `position` | `Vector` | Relative position. |

```lua
-- Move a node 5 units along X
self:SetPosition(Vec(5, 0, 0))
```

## Rotation Helpers

### `Node3D:AddRotation(rotEuler)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `rotEuler` | `Vector` | Rotation delta in degrees. |

### `Node3D:RotateAround(pivot, axis, degrees)`

| Parameter | Type | Description |
|-----------|------|-------------|

## Orientation

## Bone & Socket Attachment

### `Node3D:AttachToBone(skelMeshNode, boneName, keepWorldTransform, childIndex)`

Attach this node to a specific bone on a `SkeletalMesh3D`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `skelMeshNode` | `SkeletalMesh3D` | Mesh node to attach to. |
| `boneName` | `string` | Bone name. |
| `keepWorldTransform` | `boolean` | Maintain world-space transform. Defaults to `false`. |
| `childIndex` | `integer` | Position in parent's child array. `0` appends at end. |

---

### `Node3D:AttachToSocket(skelMeshNode, socketName, keepWorldTransform, childIndex)`

Attach this node to a named socket on a `SkeletalMesh3D`. If no socket by that name exists, it falls back to treating the name as a bone name.

<Tip>Use `AttachToSocket` for the initial attachment. To move an already-attached node between sockets on the same parent (e.g. draw/sheathe a weapon), use `SetAttachSocket` instead — it avoids the reparent overhead.</Tip>

| Parameter | Type | Description |
|-----------|------|-------------|
| `skelMeshNode` | `SkeletalMesh3D` | Mesh node to attach to. |
| `socketName` | `string` | Socket or bone name. |
| `keepWorldTransform` | `boolean` | Maintain world-space transform. Defaults to `false`. |
| `childIndex` | `integer` | Position in parent's child array. `0` appends at end. |

---

### `Node3D:SetAttachSocket(socketName)`

Move this node to a different socket or bone on its current parent without reparenting. Pass an empty string to stop following the bone and follow the parent's own transform instead.

| Parameter | Type | Description |
|-----------|------|-------------|
| `socketName` | `string` | Socket or bone name. Empty string detaches. |

```lua
sword:AttachToSocket(character, "Sheath_Back")   -- initial attach
sword:SetAttachSocket("WeaponHand_R")            -- draw
sword:SetAttachSocket("Sheath_Back")             -- sheathe
```

---

### `Node3D:GetAttachSocket()`

Get the name of the socket or bone this node is currently attached to.

**Returns:** `string` — socket or bone name, or empty string if not attached.

---

## Transform Update

### `Node3D:UpdateTransform(updateChildren)`

Force a recalculation of this node's transform matrix. Normally automatic; only needed in unusual ordering scenarios.

| Parameter | Type | Description |
|-----------|------|-------------|
| `updateChildren` | `boolean` | If `true`, recursively update all children too. |

## Usage Examples

```lua
-- Smoothly chase a target position each frame
function CameraRig:Tick(dt)
    local targetPos = self.target:GetWorldPosition() + Vec(0, 5, -10)
    local current   = self:GetWorldPosition()
    self:SetWorldPosition(Vector.Damp(current, targetPos, 0.01, dt))
    self:LookAt(self.target:GetWorldPosition())
end
```

```lua
-- Instantiate a mesh and place it at a named spawn point
function Level:SpawnEnemy(spawnNode)
    local enemy = Node.Construct("SkeletalMesh3D")
    enemy:SetWorldPosition(spawnNode:GetWorldPosition())
    enemy:SetWorldRotation(spawnNode:GetWorldRotation())
    self:AddChild(enemy)
end
```
