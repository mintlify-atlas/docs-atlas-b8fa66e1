Polyphase provides two mesh node types built on a common `Mesh3D` base class. `StaticMesh3D` renders a non-animated triangle mesh. `SkeletalMesh3D` renders a skinned mesh and drives it with a multi-slot animation system that supports blending, queuing, and animation event notifies.

All three classes also inherit from [`Primitive3D`](/lua/nodes/physics-nodes), [`Node3D`](/lua/nodes/node3d), and [`Node`](/lua/nodes/node).

---

## Mesh3D (base class)

`Mesh3D` is the common base for both static and skeletal mesh nodes. It handles material assignment and the billboard option.

### `Mesh3D:GetMaterial()`

Get the material this mesh uses for rendering. Returns the material override if one is set, otherwise returns the mesh asset's own material.

**Returns:** `Material` — active rendering material.

---

### `Mesh3D:GetMaterialOverride()`

Get the override material assigned to this node instance.

**Returns:** `Material` — override material, or `nil` if none is set.

---

### `Mesh3D:SetMaterialOverride(material)`

Assign an override material to this node. The override takes precedence over whatever material the mesh asset specifies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `material` | `Material` | Override material, or `nil` to clear. |

```lua
local mat = LoadAsset("Materials/M_Highlight")
self.mesh:SetMaterialOverride(mat)
```

---

### `Mesh3D:InstantiateMaterial()`

Create a new `MaterialInstance` based on the mesh's current material and assign it to this node. Useful for per-instance parameter changes.

**Returns:** `Material` — the newly created material instance.

```lua
local inst = self.mesh:InstantiateMaterial()
inst:SetVectorParameter("Color", Vec(1, 0, 0, 1))
```

---

### `Mesh3D:IsBillboard()`

Check whether this mesh is set to billboard (always face the camera).

**Returns:** `boolean` — `true` if billboarding is enabled.

---

### `Mesh3D:SetBillboard(billboard)`

Enable or disable billboard rendering. Billboarded meshes always rotate to face the camera.

| Parameter | Type | Description |
|-----------|------|-------------|
| `billboard` | `boolean` | Whether to billboard. |

---

## StaticMesh3D

`StaticMesh3D` renders a non-animated `StaticMesh` asset.

### `StaticMesh3D:SetStaticMesh(mesh)`

Set the static mesh asset to render.

| Parameter | Type | Description |
|-----------|------|-------------|
| `mesh` | `StaticMesh` | Static mesh asset. |

---

### `StaticMesh3D:GetStaticMesh()`

Get the static mesh asset assigned to this node.

**Returns:** `StaticMesh` — the assigned mesh asset.

---

### `StaticMesh3D:SetUseTriangleCollision(triCollision)`

Allow or disallow triangle-mesh collision. The mesh asset must also have "Generate Triangle Collision" enabled. Triangle collision should only be used on non-moving objects due to performance cost.

| Parameter | Type | Description |
|-----------|------|-------------|
| `triCollision` | `boolean` | Enable triangle collision. |

---

### `StaticMesh3D:GetUseTriangleCollision()`

Check whether triangle collision is enabled.

**Returns:** `boolean` — `true` if triangle collision is active.

---

### `StaticMesh3D:GetBakeLighting()`

Check whether this node uses baked lighting.

**Returns:** `boolean` — `true` if baked lighting is enabled.

```lua
-- Swap meshes at runtime
function Prop:Upgrade()
    local newMesh = LoadAsset("Meshes/SM_PropUpgraded")
    self:SetStaticMesh(newMesh)
end
```

## SkeletalMesh3D

`SkeletalMesh3D` renders a skinned mesh and supports a multi-slot animation system capable of blending up to eight animations simultaneously.

### `SkeletalMesh3D:SetSkeletalMesh(mesh)`

Assign a skeletal mesh asset.

| Parameter | Type | Description |
|-----------|------|-------------|
| `mesh` | `SkeletalMesh` | Skeletal mesh asset. |

---

### `SkeletalMesh3D:GetSkeletalMesh()`

Get the currently assigned skeletal mesh asset.

**Returns:** `SkeletalMesh` — the mesh asset.

---

## Animation Playback

### `SkeletalMesh3D:PlayAnimation(animName, slot, loop, speed, weight)`

Play an animation. Up to eight slots (0–7) can play simultaneously; blending is controlled by `weight`. Pass `slot = -1` to use the next available slot.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Name of the animation to play. |
| `slot` | `integer` | Animation slot (0–7). `-1` auto-selects. |
| `loop` | `boolean` | Whether to loop. Defaults to `false`. |
| `speed` | `number` | Playback speed multiplier. `1` = normal. |
| `weight` | `number` | Blend weight. `1` = full weight. |

```lua
self.mesh:PlayAnimation("Run", 0, true, 1.0, 1.0)
```

---

### `SkeletalMesh3D:StopAnimation(animName, cancelQueued)`

Stop a specific animation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Name of the animation to stop. |
| `cancelQueued` | `boolean` | Also remove it from the play queue if not yet started. |

---

### `SkeletalMesh3D:StopAllAnimations(cancelQueued)`

Stop all currently playing animations.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cancelQueued` | `boolean` | Also remove all queued animations. |

---

### `SkeletalMesh3D:IsAnimationPlaying(animName)`

Check whether a specific animation is playing.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Animation name. |

**Returns:** `boolean` — `true` if playing.

---

### `SkeletalMesh3D:QueueAnimation(animName, dependentAnimName, slot, loop, speed, weight)`

Queue an animation to play after another finishes. If no `dependentAnimName` is given, it waits for the highest-slot animation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Animation to queue. |
| `dependentAnimName` | `string` | Wait for this animation to finish. `nil` = highest slot. |
| `slot` | `integer` | Slot to use. `-1` auto-selects. |
| `loop` | `boolean` | Whether to loop. |
| `speed` | `number` | Speed multiplier. |
| `weight` | `number` | Blend weight. |

---

### `SkeletalMesh3D:CancelQueuedAnimation(animName)`

Cancel a specific queued animation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Name of the queued animation. |

---

### `SkeletalMesh3D:CancelAllQueuedAnimations()`

Cancel all queued animations.

---

### `SkeletalMesh3D:ResetAnimation()`

Reset all animations to their first frame.

## Animation Notifies

### `SkeletalMesh3D:AddAnimationNotify(animName, normalizedTime, callback)`

Register a callback that fires every time playback crosses a specific normalized point in an animation. Returns a handle for removal.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Animation to watch. |
| `normalizedTime` | `number` | Trigger point from `0` to `1`. |
| `callback` | `function` | Called when playback crosses the point. |

**Returns:** `integer` — handle for `RemoveAnimationNotify`, or `-1` on failure.

<Warning>Notifies only fire while the animation's time is advancing. Under the default `AnimationUpdateMode.OnlyUpdateWhenRendered`, off-screen characters do not advance animations. For gameplay-critical notifies, call `SetAnimationUpdateMode(AnimationUpdateMode.AlwaysUpdateTime)`.</Warning>

```lua
function Player:Start()
    self.mesh:AddAnimationNotify("DrawSword", 0.4, function()
        self.sword:SetAttachSocket("WeaponHand_R")
    end)
end
```

---

### `SkeletalMesh3D:RemoveAnimationNotify(handle)`

Remove a previously registered notify.

| Parameter | Type | Description |
|-----------|------|-------------|
| `handle` | `integer` | Handle returned by `AddAnimationNotify`. |

---

### `SkeletalMesh3D:ClearAnimationNotifies(animName)`

Remove all notifies, or just those for one animation if `animName` is provided.

| Parameter | Type | Description |
|-----------|------|-------------|
| `animName` | `string` | Optional. Omit to remove all notifies on this node. |

---

### `SkeletalMesh3D:SetAnimEventHandler(handlerFunc)`

Set a handler for DCC-authored animation events (bones named `Event_MyAnimEvent`). The handler is called with the event name whenever the keyframe is reached.

| Parameter | Type | Description |
|-----------|------|-------------|
| `handlerFunc` | `function` | Function invoked when any anim event fires. |

## Material Slots

### `SkeletalMesh3D:GetNumMaterialSlots()`

Get the number of per-section material slots on this node.

**Returns:** `integer` — slot count.

---

### `SkeletalMesh3D:GetMaterialSlot(slotOrName)`

Resolve the material that will render a given section, walking the full lookup chain: node override → section material → mesh default.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slotOrName` | `integer\|string` | 1-based slot index or section name. |

**Returns:** `Material` — resolved material.

---

### `SkeletalMesh3D:SetMaterialSlot(slotOrName, material)`

Override the material for one section on this node instance without affecting the mesh asset. Pass `nil` to clear the override.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slotOrName` | `integer\|string` | 1-based slot index or section name. |
| `material` | `Material` | New material, or `nil` to clear. |

```lua
local bodyMat = LoadAsset("Materials/M_CharBody_Red")
self.mesh:SetMaterialSlot("Body", bodyMat)
```

---

### `SkeletalMesh3D:FindMaterialSlot(name)`

Look up a section's slot index by section name.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `string` | Section name. |

**Returns:** `integer` — 1-based slot index, or `0` if not found.

## Full Example

```lua
function Character:Start()
    -- Assign mesh and material
    self.mesh = self:FindChild("Mesh")
    self.mesh:SetSkeletalMesh(LoadAsset("Meshes/SK_HeroMale"))

    -- Override one section's material per instance
    local armor = LoadAsset("Materials/M_Armor_Blue")
    self.mesh:SetMaterialSlot("Armor", armor)

    -- Play idle in slot 0, footstep sounds via notify
    self.mesh:PlayAnimation("Idle", 0, true)
    self.mesh:AddAnimationNotify("Walk", 0.5, function()
        Audio.PlaySound2D("Footstep")
    end)
end

function Character:Tick(dt)
    if self.moving then
        if not self.mesh:IsAnimationPlaying("Walk") then
            self.mesh:StopAnimation("Idle")
            self.mesh:PlayAnimation("Walk", 0, true)
        end
    end
end
```
