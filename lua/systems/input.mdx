The `Input` global gives Lua scripts unified access to every supported input device: keyboard, mouse, gamepad/joystick, touch screen, and pointer. All functions return state for the current frame. "Pressed" means the button transitioned from up to down this frame; "down" means it is held; "released" means it transitioned from down to up this frame.

---

## Keyboard

### Input.IsKeyDown

```lua
down = Input.IsKeyDown(key)
```

Returns `true` while the specified key is held.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `Key (integer)` | Key constant — see the `Key` enum |

| Return | Type | Description |
|--------|------|-------------|
| `down` | `boolean` | Key is currently held |

---

### Input.IsKeyPressed

```lua
pressed = Input.IsKeyPressed(key)
```

Returns `true` only on the frame the key is first pressed down.

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `Key (integer)` | Key to check |

| Return | Type | Description |
|--------|------|-------------|
| `pressed` | `boolean` | Key was just pressed this frame |

---

### Input.IsKeyPressedRepeat

```lua
pressed = Input.IsKeyPressedRepeat(key)
```

Like `IsKeyPressed` but fires repeatedly while the key is held, mimicking OS key-repeat behaviour (useful for text-editing UI).

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `Key (integer)` | Key to check |

| Return | Type | Description |
|--------|------|-------------|
| `pressed` | `boolean` | Key pressed or auto-repeating this frame |

---

### Input.ConvertKeyCodeToChar

```lua
char = Input.ConvertKeyCodeToChar(code)
```

Converts a `Key` integer constant to its ASCII character string.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `Key (integer)` | Key constant to convert |

| Return | Type | Description |
|--------|------|-------------|
| `char` | `string` | Single-character string |

```lua
-- Basic keyboard character input
function TextField:Tick(dt)
    local keys = Input.GetKeysPressed()
    for _, k in ipairs(keys) do
        local ch = Input.ConvertKeyCodeToChar(k)
        if ch ~= "" then
            self.text = self.text .. ch
        end
    end
    if Input.IsKeyPressed(Key.Backspace) then
        self.text = self.text:sub(1, -2)
    end
end
```

### Input.TrapCursor

```lua

```

| Parameter | Type | Description |
|-----------|------|-------------|
| `trap` | `boolean` | Enable cursor trapping |

---

### Input.LockCursor

```lua
Input.LockCursor(lock)
```

Locks the cursor to the screen centre. Typically combined with `ShowCursor(false)` and `TrapCursor(true)` for first-person camera control.

| Parameter | Type | Description |
|-----------|------|-------------|
| `lock` | `boolean` | Enable cursor locking |

---

### Input.SetCursorPosition

```lua
Input.SetCursorPosition(x, y)
```

Moves the cursor to the given screen-space pixel position.

| Parameter | Type | Description |
|-----------|------|-------------|
| `x` | `integer` | X position in pixels |
| `y` | `integer` | Y position in pixels |

```lua
-- First-person mouse look setup
function FPSController:Start()
    Input.ShowCursor(false)
    Input.TrapCursor(true)
    Input.LockCursor(true)
end

function FPSController:Tick(dt)
    local dx, dy = Input.GetMouseDelta()
    self.yaw   = self.yaw   + dx * self.sensitivity
    self.pitch = self.pitch + dy * self.sensitivity
end
```

### Input.IsGamepadConnected

```lua
connected = Input.IsGamepadConnected(index)
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `index` | `integer` | `1` | Gamepad port |

| Return | Type | Description |
|--------|------|-------------|
| `connected` | `boolean` | Whether a gamepad is plugged into that port |

```lua
-- Gamepad movement example
function Player:Tick(dt)
    if not Input.IsGamepadConnected(1) then return end

    local moveX = Input.GetGamepadAxis(Gamepad.LeftStickX, 1)
    local moveY = Input.GetGamepadAxis(Gamepad.LeftStickY, 1)
    self:Move(Vec(moveX, 0, moveY) * self.speed * dt)

    if Input.IsGamepadPressed(Gamepad.A, 1) then
        self:Jump()
    end
end
```

## Soft Keyboard

### Input.ShowSoftKeyboard

```lua
text = Input.ShowSoftKeyboard(show)
```

Shows or hides the on-screen software keyboard. On Android the keyboard is asynchronous and this function returns `nil`. On 3DS input is synchronous and the entered text is returned directly when `show` is `true`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `show` | `boolean` | Whether to show the keyboard |

| Return | Type | Description |
|--------|------|-------------|
| `text` | `string\|nil` | Input text (3DS synchronous) or `nil` (async platforms) |

---

### Input.IsSoftKeyboardShown

```lua
shown = Input.IsSoftKeyboardShown()
```

| Return | Type | Description |
|--------|------|-------------|
| `shown` | `boolean` | Whether the software keyboard is currently visible |
