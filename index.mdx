Polyphase Engine is a cross-platform 3D game engine that lets you write your game once and ship it to GameCube, Wii, Nintendo 3DS, Windows, Linux, macOS, and Android. It features a fully-integrated visual editor, a Lua scripting layer with complete engine API bindings, a node graph visual programming system, and a native C++ addon architecture with hot-reloading.

## What is Polyphase Engine?

Polyphase is a modernized fork of [Octave Engine](https://github.com/mholtkamp/octave) built around a single unifying goal: one editor, one scripting language, every retro and modern platform. The engine compiles to Vulkan on desktop, GX on GameCube/Wii, and Citro3D on 3DS — all from the same project file.

## Get Up and Running

<Steps>
  <Step title="Set up your environment">
    Install the platform toolchains for your OS: [Windows](/setup/windows), [Linux](/setup/linux), or [macOS](/setup/mac).
  </Step>
  <Step title="Build or download the editor">
    Compile from source with Visual Studio, VS Code, or `make` — or grab a prebuilt release from the GitHub Releases page.
  </Step>
  <Step title="Create a project and a scene">
    Launch the editor, click **Create New Project**, add a **StaticMesh3D** node to a scene, and save.
  </Step>
  <Step title="Package for your target platform">
    Open **File → Build Profiles**, select your platform (Wii, GameCube, 3DS, Windows, Android…), and click **Build**.
  </Step>
</Steps>
